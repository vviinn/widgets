# VUE

In order to use the custom element library within the Vue app, the application must be modified to define the custom elements and to inform the Vue compiler which elements to ignore during compilation. This can all be done within the `main.js` file.

Run `npm install --save mediaopt-vpr` to install component.

```javascript
import Vue from 'vue';
import App from './App.vue';

import { applyPolyfills, defineCustomElements } from 'mediaopt-vpr/loader';

Vue.config.productionTip = false;
Vue.config.ignoredElements = [/mediaopt*/];

applyPolyfills().then(() => {
  defineCustomElements();
});

new Vue({
  render: h => h(App)
}).$mount('#app');
```

The components should then be available in any of the Vue components

```javascript
render() {
  return (
    <div>
      <mopt-vpr></mopt-vpr>
    </div>
  )
}
```
