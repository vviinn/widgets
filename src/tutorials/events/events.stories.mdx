# Listening events

Every product generate three events:

| Event                 | Description                                                  | Type                                                                                                                                                                                                               |
| --------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `recommendationClick` | Event fires ones when user click on deeplink                 | `CustomEvent<{ productId?: string; title?: string; brand?: string; productType?: string; deeplink?: string; image?: { original?: string; thumbnail?: string; }; price?: { actual?: number; retail?: number; }; }>` |
| `recommendationLoad`  | Event fires ones when recommendation rendered on page        | `CustomEvent<{ productId?: string; title?: string; brand?: string; productType?: string; deeplink?: string; image?: { original?: string; thumbnail?: string; }; price?: { actual?: number; retail?: number; }; }>` |
| `recommendationView`  | Event fires ones when recommendation appears on the viewport | `CustomEvent<{ productId?: string; title?: string; brand?: string; productType?: string; deeplink?: string; image?: { original?: string; thumbnail?: string; }; price?: { actual?: number; retail?: number; }; }>` |

User can work with this events with `addEventListener` method if use vanilla JavaScript or with methods common for framework used.

## Recommendation load and view

```javascript
const component = document.querySelector('mopt-vpr');

component.addEventListener('recommendationLoad', ({detail}) => {
  console.log(`Load product ${detail.title} with id ${detail.productId}`);
});

component.addEventListener('recommendationView', ({detail}) => {
  console.log(`Product ${detail.title} with id ${detail.productId} is rendered on viewport`);
});
```

## Recommendation click

When deeplink is clicked component dispatch recommendationClick and user go to product.
Because of that use [Beacon API](https://developer.mozilla.org/en-US/docs/Web/API/Beacon_API) to handle this events.

```javascript
const component = document.querySelector('mopt-vpr');

component.addEventListener('recommendationClick', ({detail}) => {
  navigator.sendBeacon(some_url, detail);
});
```
