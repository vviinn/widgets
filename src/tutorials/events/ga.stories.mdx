# Default analytics

By default Web Component can send Enhanced Ecommerce data to customer Google Analytics account.

Events will be sent only if global `gtag` or `ga` function initialized.
Gtag is preferred method of tracking ecommerce data.

Each product have will belong to `VI VPR View` list in analytics platform.
