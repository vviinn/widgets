# Default analytics

By default Web Component can send some events to customer Google Analytics account.
  
Events will be sent only if global `ga` function initialized.

Each event have category `VI-Product`. Event label depends on event type:

|Event type           |label|
|---------------------|-----|
|recommendationClick|click|
|recommendationLoad |load |
|recommendationView |view |

Also Web component will sent product id in label property of sent event.

If you want to customize this behaviour
