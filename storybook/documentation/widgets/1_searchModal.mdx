# Search Modal 

The `Search Modal` is a full-screen overlay that allows:
 - Search for products via already existing images (default behavior).
 - Text Search with the "text-search-show" property set to "true".
 - Use Upload Mode to directly open the image upload by clicking the button.
 - Use Camera Mode for capturing new images for search with a device's camera, which will ask for permission to use the camera if it's not granted yet.
