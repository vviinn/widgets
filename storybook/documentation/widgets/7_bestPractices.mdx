# Best Practices

<div className="best-practices-list">
  <ol>
    <li>
      If you are making a <b>TEXT SEARCH</b> and redirecting to show the results on another page, prefer to use the <code>search-query</code> parameter and pass a query to the <code>vviinn-text-search</code> component, if it exists on the page.
    </li>
    <li>
      When you have already redirected to the results page and show initial results using the <code>searchId</code> or <code>query</code> parameter from your URL:
      <ul>
        <li>For other searches on the <b>SAME PAGE</b>, you don't need to pass any parameters, components will handle the new query or the new image upload. Passing parameters again could lead to unexpected results.</li>
        <li>To support reloading or going back, e.g., from the Product Details page, you should update the URL preferred without refreshing the page. If you don't use the SPA framework, you could use [pushState](https://developer.mozilla.org/en-US/docs/Web/API/History/pushState) or [replaceState](https://developer.mozilla.org/en-US/docs/Web/API/History/replaceState) browser history API methods.</li>
        <li>To support refreshing the page without losing the image, you could use the <code>save-image-mode=always</code> parameter for the <code>vviinn-cropper</code> component.</li>
      </ul>
    </li>
  </ol>
</div>
