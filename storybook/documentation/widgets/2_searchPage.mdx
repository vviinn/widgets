# Search Page

Using `Vviinn Widgets` as separate components allows for greater control over the layout of the widgets and supports a wider range of use cases. For example, you can combine `Text Search` and `Visual Search` functionality while refining results with filters, and display them on the same page or even on different pages.

## Components List

Here is a list of the available components:

- [vviinn-text-search](?path=/story/widgets-search--text-search) - a text search input field that allows users to search by text or upload an image
- [vviinn-filters](?path=/story/elements-filters--main), [vviinn-extended-filters](?path=/story/elements-filters--extended) - a set of filters that allow users to refine their search results
- [vviinn-results](?path=/story/elements-product-listing--static-filters) - a container that displays the search results

## Integration

To integrate the components into your project, install the `vviinn-widgets` package using one of the methods mentioned in the [Installation](?path=/docs/getting-started-installation--docs) section. Ensure you install at least version [2.76.1](https://www.npmjs.com/package/vviinn-widgets/v/2.76.1) of the package to use the components. However, using the latest version is recommended.


## Summary

You can use the components in a framework-agnostic way or integrate them into your project using a specific framework. The components can be used together or separately, depending on your needs. They are highly customizable and suitable for a wide range of use cases.
