# Search Modal 

The Search Modal is a full-screen overlay that allows users to search for products using text (Text mode) or already existing images (Image mode) or capture new image for search with a device camera (Camera mode, will ask for permission to use camera if not granted yet). It can be opened by clicking the search icon in the header of the Text Search widget.
