# Product List

The `vviinn-results` component displays search results on the page. It works in two modes:

## Event-Based (Default)

Place `vviinn-results` on the same page as `vviinn-text-search` or `vviinn-vps-button`. The components communicate via events (`vviinnTextSearchStarted`, `vviinnImageUploadFinished`) and a shared store — no additional configuration needed.

You can also trigger a search directly by setting `text-search-query` or `search-id` props on `vviinn-results`.

## Automatic Redirect with URL Parameters

When search components (`vviinn-text-search`, `vviinn-vps-button`) have `results-page-url` set, they redirect the user to a dedicated results page with URL parameters:

- Text search: `/results?query=shoes`
- Image search: `/results?searchId=abc-123`

The `vviinn-results` component automatically parses these parameters on page load and triggers the corresponding search.

If `text-search-query` or `search-id` props are set explicitly, they take priority over URL parameters.
