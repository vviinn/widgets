# Filters

The filters components allow users to refine product search results. There are two main components: `vviinn-filters` displays selected primary filters in compact mode, while `vviinn-extended-filters` shows all activated filters with multiple display modes.

<p>In order to see the results, you need to use this component in combination with other components like Product List.</p>
