# Vue

To use the custom element library within the Vue app, the application must be modified to define the custom elements and to inform the Vue compiler which elements to ignore during compilation. This can all be done within the `main.js/ts` file.

As you see in the following example, we imported `applyPolyfills` and `defineCustomElements` from `vviinn-widgets/dist/loader` and then in the next line calling `applyPolyfills()` and `defineCustomElements()` to register the Vviinn widgets. The rest is related to Vue itself.

`main.js/main.ts`

```javascript
import './assets/main.css'

import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

import { applyPolyfills, defineCustomElements } from 'vviinn-widgets/dist/loader'

applyPolyfills().then(() => {
  defineCustomElements()
})

const app = createApp(App)

app.use(router)

app.mount('#app')
```

`In a Vue component`

```javascript
<script setup lang="ts"></script>

<template>
  <vviinn-vps-button token="YOUR_TOKEN"></vviinn-vps-button>
</template>

<style scoped></style>
```

## \[Vue warn]: Failed to resolve component: ...

If you see the following Vue warning in the browser console:

`If this is a native custom element, make sure to exclude it from component resolution via compilerOptions.isCustomElement.`

You can fix it by adding the following code to the `vue.config.js/ts` file:

```javascript
export default defineConfig({
  plugins: [
    ...
    vue({
      template: {
        compilerOptions: {
          isCustomElement: (tag) => {
            return tag.startsWith('vviinn-')
          }
        }
      }
    }),
    ...
  ],
  ...
})
```

## Troubleshooting

Sometimes other libraries define custom elements and there would be some conflict. In this case, you can integrate Vviinn widgets as explained in the [Frameworkless](?path=/docs/installation-frameworkless--docs) section.

For more information, check [Stencil documentation](https://stenciljs.com/docs/vue)
