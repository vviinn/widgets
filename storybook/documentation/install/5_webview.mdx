# WebView

In mobile app development, a `WebView` is an essential component that allows you to display web content within your native `Android` or `iOS` app. Therefore, in this section we want to show you how to integrate `Vviinn Widgets` as a web component in a mobile app.

If you are interested to learn more about the `WebView` component, you can check the official documentation for [Android](https://developer.android.com/reference/android/webkit/WebView) and [iOS](https://developer.apple.com/documentation/webkit/wkwebview). Also if you are developing mobile apps with Cross-Platform development technologies, there are some popular libraries like [React Native WebView](), and [Cordova WebView](), [Flutter WebView](), [Ionic WebView](), and ... that you can use based on your desire development technologie.
