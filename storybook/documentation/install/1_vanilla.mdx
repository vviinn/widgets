# JavaScript

## Install using CDN

Paste scripts to the `head` section of your page.<br />
You don't need to include a script tag with `nomodule` attribute if you don't need to support browsers without JavaScript modules feature.

```html
<script
  type="module"
  src="STORYBOOK_CDN_PATH/STORYBOOK_NPM_PACKAGE_NAME.esm.js"
></script>
<script
  nomodule
  src="STORYBOOK_CDN_PATH/STORYBOOK_NPM_PACKAGE_NAME.js"
></script>
```

Then you will be able to use VPR or VPS widgets.

### Recommendation Widget

To use recommendation widget, insert a snippet below where you want to render the widget.<br />
`token` and `product-id` attributes are only necessary, but you can tweak the widget with other attributes.

```html
<STORYBOOK_VPR_WIDGET_TAG token="YOUR_TOKEN" product-id="YOUR_PRODUCT_ID">
</STORYBOOK_VPR_WIDGET_TAG>
```

[Check other attributes here ](?path=/story/widgets-recommendation-main--continuity)

Also, it’s possible to create the component instance with DOM API:

```javascript
const component = document.createElement("STORYBOOK_VPR_WIDGET_TAG");
component.token = YOUR_TOKEN;
component.productId = YOUR_PRODUCT_ID;

document.append(component);
```

### Search Widget

To use the search widget, first, insert the snippet below anywhere on the page.
The widget is implemented as a modal window, so you need to trigger it.

```html
<STORYBOOK_VPS_WIDGET_TAG token="YOUR_TOKEN"></STORYBOOK_VPS_WIDGET_TAG>
```

[Check other attributes here ](?path=/story/widgets-search-main--default)

You can also create a component instance with DOM API:

```javascript
const component = document.createElement("STORYBOOK_VPS_WIDGET_TAG");
component.token = YOUR_TOKEN;

document.append(component);
```

## Install using NPM

If you want to use widgets as ES6 modules you should install them from NPM.

`npm i STORYBOOK_NPM_PACKAGE_NAME`

And then add it to your JavaScript code:

```javascript
import { defineCustomElements } from "STORYBOOK_NPM_PACKAGE_NAME";
defineCustomElements();
```

After that, you can use both Recommendation or Search Widgets in an HTML template or with Javascript.
