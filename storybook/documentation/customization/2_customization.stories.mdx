# Customization

There is a possibility to not only style widgets using CSS APIs but also
customize some content using [slots](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_templates_and_slots#adding_flexibility_with_slots).

Here are slots you can use for Visual Recommendation Button (`vviinn-vpr-button`):

- button – _vpr button container_
- vviinn-button – _vpr button itself_

Here are slots you can use in Visual Product Search widgets (`vviinn-vps-widget` and `vviinn-vps-button`):

- vviinn-example-images-1 – _the first image in the example images block_
- vviinn-example-images-2 – _the second image in the example images block_
- vviinn-example-images-3 – _the third image in the example images block_
- vviinn-example-images-4 – _the fourth image in the example images block_
- vviinn-example-images-title – _header of example images block_
- vviinn-image-search-modal-title – _title on the top of search results_
- vviinn-image-upload-button-text – _title of upload button_
- onboarding-card-1-icon – _icon (or other graphics) on the first onboarding slide_
- onboarding-card-1-text – _text content of the first onboarding slide_
- onboarding-card-2-icon – _icon (or other graphics) on the second onboarding slide_
- onboarding-card-2-text – _text content of the second onboarding slide_
- onboarding-card-3-icon – _icon (or other graphics) on the third onboarding slide_
- onboarding-card-3-text – _text content of the third onboarding slide_
- vviinn-onboarding-title – _title of onboarding section_
- vviinn-privacy-badge-text – _text content of privacy notification block_
- vviinn-teaser-text – _text on the widget's main screen_

Also, `vviinn-vps-button` uses a "default" slot for icon customization.
Here is a code example:

```html

    xmlns="http://www.w3.org/2000/svg"

    height="50"

    <path stroke="none" d="M0 0h24v24H0z" />
    <circle cx="12" cy="14" r="7" />

    <path d="M10 10.5c1.333.667 2.667.667 4 0" />

</vviinn-vps-button>
```

The slot has no restrictions for any element type so any SVG or HTML will be valid.

```html
<vviinn-vps-button>
  <span>I'm looking like text, but try to click!</span>
</vviinn-vps-button>
```

Let's improve the example above and customize `vviinn-onboarding-title`. When we use any named slots with `vviinn-vps-button` we also need to provide an icon to "default" slot.

```html
<vviinn-vps-button>
  <style>
    /* We need to hide slots on the page, to not show them outside the widget */
    vviinn-vps-button [slot] {
      visibility: hidden;
      position: absolute;
    }
  </style>
  <!-- svg will be added to "default" slot because it hasn't slot attribute -->
  <svg width="22" height="20" fill="none" xmlns="http://www.w3.org/2000/svg">
    <path
      fill-rule="evenodd"
      clip-rule="evenodd"
      d="M16.567 3H19A3.01 3.01 0 0 1 22 6v7.69h-2V6c0-.55-.451-1-1.001-1h-3.502l-2.03-3H8.543L6.603 5H3.001c-.55 0-1 .45-1 1v11c0 .55.45 1 1 1h5.933v2H3.001A3.01 3.01 0 0 1 0 17V6c0-1.65 1.35-3 3.001-3h2.522l1.94-3h7.074l2.03 3Zm-5.562 3c1.28 0 2.561.48 3.542 1.46h-.01a4.992 4.992 0 0 1 .64 6.29l3.051 3.05-1.41 1.41-3.052-3.05c-.84.55-1.8.83-2.76.83-1.282 0-2.562-.48-3.543-1.46a5.002 5.002 0 0 1 0-7.07A5.026 5.026 0 0 1 11.005 6Zm-2.771 5a2.763 2.763 0 0 0 2.771 2.77A2.763 2.763 0 0 0 13.776 11a2.763 2.763 0 0 0-2.771-2.77A2.763 2.763 0 0 0 8.234 11Z"
      fill="#161616"
    />
  </svg>
  <!-- Our named slot -->
  <h3 slot="vviinn-onboarding-title">Your custom title</h3>
</vviinn-vps-button>
```

## Images customization example

In general, you can use any valid HTML or SVG content inside slots, but for example, with images, you should use a special component that will fire search events:

```html
<vviinn-example-image src="URL" slot="vviinn-example-images-1"></vviinn-example-image>
```

For now, the image should be stored in vviinn cdn.
