# Replace Widget Content

Want to change "Add to Basket" to "Add to Cart"? Use your own icons? **Slots let you replace default text and content** with your own HTML.

Add your content with the **`slot` attribute** to place it inside the widget. Learn more about [Slots](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_templates_and_slots#adding_flexibility_with_slots).

The `width: 0; height: 0` in the examples keeps percent-sized slot content, such as an icon with `width="100%"`, from adding a horizontal scrollbar.

## Available in These Widgets

- [Discovery Slider](#discovery-slider-example)
- [Discovery Set](#discovery-set-example)
- [Search Modal](#search-modal)
- [Filters](#filters)
- [Product List](#product-list)
