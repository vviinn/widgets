# Style CSS Parts

To style elements of `Vviinn Widgets` with CSS you can use [Shadow Parts](https://developer.mozilla.org/en-US/docs/Web/CSS/::part). 

## List of Shadow Parts 

Each component has its own set of Shadow Parts. You can see a list of each in the Playground section of this documentation.
For example, [check](?path=/story/playground-discovery--default) the list of available Shadow Parts for Discovery Slider at the bottom of the Controls tab (right sidebar).
