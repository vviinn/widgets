# Style CSS Parts

In order to style elements of Vviinn Widgets you can use [Shadow Parts](https://developer.mozilla.org/en-US/docs/Web/CSS/::part). 

## List of Shadow Parts 

Each component has itws own set of Shadow Parts that you can see list of each in the Playground section of this documentation.
For example, [check](?path=/story/playground-discovery--grid) the list of available Shadow Parts for `vviinn-vpr-widget` component at the bottom of Controls tab(right sidebar).
