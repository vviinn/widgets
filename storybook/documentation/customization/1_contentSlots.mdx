# Content Slots

There is a possibility to not only style widgets using CSS APIs but also
customize some content using [slots](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_templates_and_slots#adding_flexibility_with_slots).

## Recommendation

Here are Slots that could be used in Recommendation Widget and Recommendation Button (`vviinn-vpr-widget` and `vviinn-vpr-button`):

* vviinn-recommendations-title - *Recommendations title text*
* vviinn-recommendations-subtitle - *Recommendations subtitle text (Set mode)*
* vviinn-update-button-text - *Text of Update Button on the top (Set mode)*
* vviinn-update-button-text - *Text of Add to Basket button*
* vviinn-basket-button-icon - *Icon of Add to Basket button (Set mode)*
* vviinn-basket-button-text-pressed - *Text of pressed Add to Basket button (Set mode)*
* vviinn-basket-button-icon-pressed - *Icon of pressed Add to Basket button (Set mode)*
* vviinn-energy-label-data-sheet-text - *Text of the data sheet link for the energy label*

There is also the default slot for `vviinn-vps-button`, which will pass to the button's content. You don't need any slot attribute for it.

## Search

Slots that could be used in Search Widget and Search Button (`vviinn-vps-widget` and `vviinn-vps-button`):

* vviinn-teaser-text – *Text on widget's main screen*
* vviinn-image-upload-button-text – *Title of Upload Button*
* vviinn-image-upload-icon - *Icon of Upload Button*
* vviinn-camera-button-text-start - *Title of Start Camera button (for Desktop)*
* vviinn-camera-button-text-stop - *Title of Stop Camera button (for Desktop)*
* vviinn-camera-icon - *Icon of Camera Button*
* vviinn-camera-capture-text - *Text above the Camera Capture button*
* vviinn-text-search-icon - *Icon of text search block*
* vviinn-privacy-badge-text – *Text content of privacy notification block*
* vviinn-image-search-modal-title – *Image search modal title*
* vviinn-energy-label-data-sheet-text - *Text of the data sheet link for the energy label*

## Filters

Slots that could be used in Extended Filters Widget (`vviinn-extended-filters`):

* vviinn-extended-filters-title – *Text on widget's header*
* vviinn-extended-filters-apply – *Title of Apply Button*
* vviinn-extended-filters-reset - *Title of Reset Button*

## Customization example of vviinn-vps-button

Let's customize `vviinn-teaser-text` and replace it with the custom text. It's important to note that when we use any named slots inside `vviinn-vps-button` we also need to provide an icon to "default" slot.

```html
<vviinn-vps-button token="YOUR_TOKEN">
  <style>
    /* We need to hide slots on the page, to not show them outside the widget */
    vviinn-vps-button [slot] {
      visibility: hidden;
      position: absolute;
    }
  </style>
  <!-- svg will be added to "default" slot because it hasn't slot attribute -->
  <svg width="22" height="20" fill="none" xmlns="http://www.w3.org/2000/svg">
    <path
      fill-rule="evenodd"
      clip-rule="evenodd"
      d="M16.567 3H19A3.01 3.01 0 0 1 22 6v7.69h-2V6c0-.55-.451-1-1.001-1h-3.502l-2.03-3H8.543L6.603 5H3.001c-.55 0-1 .45-1 1v11c0 .55.45 1 1 1h5.933v2H3.001A3.01 3.01 0 0 1 0 17V6c0-1.65 1.35-3 3.001-3h2.522l1.94-3h7.074l2.03 3Zm-5.562 3c1.28 0 2.561.48 3.542 1.46h-.01a4.992 4.992 0 0 1 .64 6.29l3.051 3.05-1.41 1.41-3.052-3.05c-.84.55-1.8.83-2.76.83-1.282 0-2.562-.48-3.543-1.46a5.002 5.002 0 0 1 0-7.07A5.026 5.026 0 0 1 11.005 6Zm-2.771 5a2.763 2.763 0 0 0 2.771 2.77A2.763 2.763 0 0 0 13.776 11a2.763 2.763 0 0 0-2.771-2.77A2.763 2.763 0 0 0 8.234 11Z"
      fill="#008080"
    />
  </svg>
  
  <!-- Our named slot -->
  <h3 slot="vviinn-teaser-text">Your custom text</h3>
</vviinn-vps-button>
```

Here is our button with the custom icon. If we click on it, we will also see the customized `vviinn-teaser-text`.

<vviinn-vps-button token={vviinnToken} locale="en-US">
  <svg width="22" height="20" fill="none" xmlns="http://www.w3.org/2000/svg">
    <path fillRule="evenodd" clipRule="evenodd" d="M16.567 3H19A3.01 3.01 0 0 1 22 6v7.69h-2V6c0-.55-.451-1-1.001-1h-3.502l-2.03-3H8.543L6.603 5H3.001c-.55 0-1 .45-1 1v11c0 .55.45 1 1 1h5.933v2H3.001A3.01 3.01 0 0 1 0 17V6c0-1.65 1.35-3 3.001-3h2.522l1.94-3h7.074l2.03 3Zm-5.562 3c1.28 0 2.561.48 3.542 1.46h-.01a4.992 4.992 0 0 1 .64 6.29l3.051 3.05-1.41 1.41-3.052-3.05c-.84.55-1.8.83-2.76.83-1.282 0-2.562-.48-3.543-1.46a5.002 5.002 0 0 1 0-7.07A5.026 5.026 0 0 1 11.005 6Zm-2.771 5a2.763 2.763 0 0 0 2.771 2.77A2.763 2.763 0 0 0 13.776 11a2.763 2.763 0 0 0-2.771-2.77A2.763 2.763 0 0 0 8.234 11Z" fill="#008080" />
  </svg>

  <h3 slot="vviinn-teaser-text">Your custom text</h3>
</vviinn-vps-button>

Anything we put between the opening and closing tags without the `slot` attribute will be placed inside the "default" slot. The slot has no restrictions for any element type. It could be an `<svg>` like in the example above or any HTML will be valid.

```html
<vviinn-vps-button token="YOUR_TOKEN" >
  <span>I'm looking like text, but try to click!</span>
</vviinn-vps-button>
```

  <span>I'm looking like text, but try to click!</span>
</vviinn-vps-button>

## Images customization example

In general, you can use any valid HTML or SVG content inside slots, but for example, with images, you should use a special component that will fire search events:

```html
<vviinn-example-image src="URL" slot="vviinn-example-image"></vviinn-example-image>
```

For now, the image should be stored in Vviinn CDN. If you need help, please contact your Vviinn representative.
