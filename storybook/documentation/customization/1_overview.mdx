# Customization Overview

Vviinn Widgets offer three powerful ways to customize appearance and content. This guide helps you choose the right approach for your needs.

## Customization Methods

### [CSS Variables](?path=/docs/customization-css-variables--docs)
Apply theme-level styles using CSS custom properties. Best for global styling and brand colors.

### [Target Styling](?path=/docs/customization-target-styling--docs)
Style specific elements inside widgets with `::part()` selector. Best for precise styling control.

### [Custom Content](?path=/docs/customization-custom-content--docs)
Replace default text, icons, and content with your own HTML. Best for changing widget content.

## Quick Start Examples

### CSS Variables: Change Primary Color
```css
vviinn-vps-button {
  --color-primary: #078688;
  --color-primary-hover: #056b67;
}
```

### Target Styling: Style Upload Button
```css
vviinn-vps-button::part(upload-photo_button) {
  background: #000;
  color: #fff;
  border-radius: 8px;
}
```

### Custom Content: Replace Button Text
```html
<vviinn-vpr-widget token="TOKEN">
  <span slot="vviinn-basket-button-text">Add to Cart</span>
</vviinn-vpr-widget>
```

---

## Combining Methods

You can use multiple customization methods together for maximum flexibility:

```html
<style>
  /* CSS Variables for theme colors */
  vviinn-vps-button {
    --color-primary: #078688;
  }

  /* Target Styling for specific elements */
  vviinn-vps-button::part(upload-photo_button) {
    border-radius: 8px;
  }
</style>

<!-- Custom Content for text -->
<vviinn-vps-button token="TOKEN">
  <span slot="vviinn-recommendations-title">You May Also Like</span>
</vviinn-vps-button>
```

## Next Steps

1. **Start with CSS Variables** if you need basic theming
2. **Use Target Styling** when you need precise control over specific elements
3. **Use Custom Content** when you need to change text or add custom content

For detailed examples and available options, visit the individual documentation pages linked above.
