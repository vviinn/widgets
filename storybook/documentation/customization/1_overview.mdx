# Customization Overview

Vviinn Widgets offer **three powerful ways** to customize appearance and content. This guide helps you choose the right approach for your needs.

## Quick Start Examples

### CSS Variables: Change Primary Color
```css
vviinn-vps-button {
  --color-primary: #078688;
  --color-primary-hover: #056b67;
}
```

### Target Styling: Style Upload Button
```css
vviinn-vps-button::part(upload-photo_button) {
  min-height: 48px;
  padding: 12px 24px;
  font-size: 16px;
}
```

### Custom Content: Replace Button Text
```html
<vviinn-vps-button token="TOKEN">
  <span slot="vviinn-image-upload-button-text">Upload Image</span>
</vviinn-vps-button>
```

## Where Your CSS Lives

### Page Stylesheet (Default)

A `<style>` or `<link>` on your page. It reaches widget elements through the widget you embed, e.g. `vviinn-vpr-widget::part(title)`. Enough for most styling.

### `css-url` Stylesheet

A file the widget loads into its own shadow root:

```html
<vviinn-results css-url="https://your-shop.example/vviinn.css"></vviinn-results>
```

Inside it, select elements directly: `vviinn-product-card::part(title)`, `:host`, `::slotted()`. Use it for what a page stylesheet can't do:

- style cards by [product data](?path=/docs/components-product-card--docs) – brand, custom labels;
- style elements inside a card by the card's state, e.g. `vviinn-product-card:hover::part(image)`.

Limits of `css-url`:

- In the search modal the cards sit inside a nested `vviinn-results`, out of reach of the `vviinn-vps-widget` stylesheet.
- On `vviinn-results` the file is also loaded into the One-Click Discovery buttons and the slider they open, so bare `:host` rules apply there too – scope layout rules with `:host(vviinn-results)`.

Across these docs, `css-url` examples begin with a `/* loaded via … css-url="..." */` comment; all other examples go into a page stylesheet.
