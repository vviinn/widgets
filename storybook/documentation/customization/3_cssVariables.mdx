# CSS Variables

Apply CSS style generally to [CSS Custom Properties (CSS Variables)](https://developer.mozilla.org/en-US/docs/Web/CSS/--*) for all or specific Vviinn widgets.

## CSS Custom Properties (CSS Variables)

### Search Modal

* \--color-primary *used on the main action button, slider bullets, selected detected object or filter, and some other parts*
* \--color-primary-hover *used on the main action button when hovering*
* \--color-icons *used in svg icons fill*

### Product Card

* \--product-card-content-align *used on the product card content alignment*
* \--product-card-text-align *used on the product card text alignment*
* \--product-card-image-border *used on the product card image border*
* \--product-card-image-bg-color *used on the product card background*

Note: all widgets that use product cards (like `vviinn-vps-widget`, `vviinn-vps-button`, and `vviinn-results`), could be customized with these variables.


## Applying CSS Variables to Widgets

Apply the CSS variables to all `Vviinn Widgets` of the pages by using the `html` selector as shown in the following example:
```css
html {
  ...
  --color-primary: #0f62fe;
  ...
}
```

If you want to apply the variables to a specific widget, you can use the widget name as a selector as shown in the following example:
```css
vviinn-vps-button {
  ...
  --color-primary: #0f62fe;
  ...
}
```
