# Styling Specific Elements

Need to style just the upload button? Or change how a title looks? **CSS Parts give you precise control** over individual widget elements.

Use the **`::part()` selector** to target specific parts that regular CSS can't reach. Learn more about [Shadow Parts](https://developer.mozilla.org/en-US/docs/Web/CSS/::part). 

## Finding Available Parts

Each widget exposes specific elements you can style. Find available parts in two ways:

1. **Playground section** - View the complete list at the bottom of the Controls tab (right sidebar). For example, [check Discovery Slider parts](?path=/story/playground-discovery--default).
2. **Browser DevTools** - Inspect the widget element and look for `part` attributes in the shadow DOM.

**Tip:** You can **combine multiple parts** in a selector to target specific elements more precisely:

```css
/* Target an element that has both parts */
vviinn-product-card::part(custom-label-1 custom-label-image) {
  border-radius: 8px;
  padding: 4px;
}
```

## Styling Slotted Content

Custom content placed in a widget's **default slot** (e.g. an SVG icon inside `vviinn-vps-button` or `vviinn-vpr-button` – same approach for both) can be styled two ways depending on where the stylesheet lives.

### From `css-url` (shadow DOM)

When the stylesheet is loaded via the widget's `css-url` prop, it lives **inside the widget's shadow root**. Use `::slotted()` to reach the same elements from that scope:

```css
/* loaded via <vviinn-vps-button css-url="..."> */
:host ::slotted(svg) {
  width: 32px;
  height: 32px;
}
```

Pick whichever scope matches where your stylesheet is hosted.

**Note:** Applies only to the **default slot** (no `slot=` attribute). Content in **named slots** (e.g. `slot="vviinn-image-upload-icon"`) is forwarded into nested components – style it via CSS Parts or CSS Variables instead.
