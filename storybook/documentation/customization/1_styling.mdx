# Styling

There are two ways of styling web components: [CSS Custom Properties](https://developer.mozilla.org/en-US/docs/Web/CSS/--*)
and [Shadow Parts](https://developer.mozilla.org/en-US/docs/Web/CSS/::part)

## Using CSS Custom Properties

You can customize `vviinn-vps-button` and `vviinn-vps-widget` with these properties:

* \--color-primary *used on the main action button, slider bullets, selected detected object or filter, and some other parts*
* \--color-primary-hover *used on the main action button when hovering*
* \--color-icons *used in svg icons fill*

```css
html {
  --color-primary: #0f62fe;
  --color-primary-hover: lightblue;
  --color-icons: rgba(255, 0, 0, 0.5);
}
```

## Using Shadow Parts

Almost every component you can use exports some Shadow Parts. Use `component-name::part(part-name)` to add CSS rules to any exported part.
For example, to style the title of product cards in `vviinn-vpr-widget` and to hide the price you can use this CSS snippet:

```css
vviinn-vpr-widget::part(title) {
  text-decoration: underline;
  font-weight: bold;
}

vviinn-vpr-widget::part(price-container) {
  display: none;
}
```

Let's style `vviinn-vps-button` using the same approach:

```css
vviinn-vps-button::part(price-regular) {
  text-decoration: underline;
  font-weight: bold;
}
```

Shadow Parts are listed in Widgets section of this documentation.
It could be *image, title, price-regular, price-sale*, and others.

For example, [check](?path=/story/widgets-recommendation-main--grid) the list of available Shadow Parts for `vviinn-vpr-widget` component at the bottom of Controls tab.
