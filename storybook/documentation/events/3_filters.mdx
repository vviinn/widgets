# Filters Events

Every Vviinn Widget has some events that users can work on and listen to these events with `document.addEventListener()`.

Events related to the filters  are mainly for internal usage inside Vviinn components, but if you need them you can also listen and send data to these components as well.

## Listen to Events. Examples

```javascript
document.addEventListener("vviinnFilters", ({ detail }) => {
  console.log(detail);
});

// Output:
{
    "productId": "123456",
    "productRank": 0,
    "productName": "Couchtisch Rolf Benz 8770",
    "productType": "Table",
    "widgetType": "VPR",
    "campaignTypeId": "VPR",
    "campaignTypeName": "Similar Products",
    "widgetId": "vpr-widget-1",
    "widgetVersion": "2.1.0"
}
// ... and other loaded products
```
