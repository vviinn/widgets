# Default analytics

By default, the Vviinn web component works with Google Analytics Enhanced Ecommerce and can send data to your Google Analytics account.

Events will only be sent if the global `gtag` or `ga` function is initialized.
`Gtag` is the preferred method of tracking ecommerce data.

Each product will belong to the Vviinn list in the analytics platform.

If you want to customize this behavior
[read more about events](?path=/docs/getting-started-events--docs)
