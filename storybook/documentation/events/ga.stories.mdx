# Default analytics

By default the vviinn web component works with Google Analytics Enhanced Ecommerce and can send data to your Google Analytics account.

Events will only be send if global `gtag` or `ga` function initialized.
Gtag is preferred method of tracking ecommerce data.

Each product have will belong to `vviinn` list in analytics platform.

If you want to customize this behaviour
