# Search Events

Every Vviinn Widget has some events that users can work on and listen to these events with `document.addEventListener()`.

All these events are available on Search (Button, Widget), and the following props are available for each event:

- campaignTypeId
- campaignTypeName
- widgetId (if exists)
- widgetVersion

Some events have additional props, summarized it table below.

## Listen to Events. Examples

```javascript
document.addEventListener("vviinnImageUploadStarted", ({ detail }) => {
  console.log(detail);
});

// Output: Search Modal
{
  "campaignTypeId": "VPS",
  "campaignTypeName": "Visual Search",
  "widgetId": "my-search-widget",
  "widgetVersion": "2.87.0",
  "isTriggeredByVpsWidget": true
}
```
