# Product Events

Every Vviinn Widget has some events that users can work on and listen to these events with `document.addEventListener()`.

All these events are available on Discovery (Button, Widget), and Search (Button, Widget) and the following props are available for each event:

- campaignTypeId
- campaignTypeName
- widgetId (if exists)
- widgetVersion

Some events have additional props, summarized it table below.

## Listen to Events. Examples

```javascript
document.addEventListener("vviinnProductLoad", ({ detail }) => {
  console.log(detail);
});

// Output:
{
    "productId": "123456",
    "productRank": 0,
    "productName": "Couchtisch Rolf Benz 8770",
    "productType": "Table",
    "campaignTypeId": "VPR",
    "campaignTypeName": "Similar Products",
    "widgetId": "my-recommendation-widget",
    "widgetVersion": "2.1.0"
}
// ... and other loaded products

document.addEventListener("vviinnRedirect", ({ detail }) => {
  console.log(detail);
  // Optionally redirect the user
  // window.location.href = detail.url;
});

// Output:
{
    "url": "https://www.trends.de/sansibar",
    "campaignTypeId": "TPS",
    "campaignTypeName": "Text Product Search",
    "widgetId": "my-search-widget",
    "widgetVersion": "2.190.0"
}
```
