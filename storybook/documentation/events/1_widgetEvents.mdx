# Widget Events

Every Vviinn Widget has some events that users can work on and listen to these events with `document.addEventListener()`.

The following props are available for each event:

- campaignTypeId
- campaignTypeName
- widgetId
- widgetVersion

## Listen to Events. Examples

```javascript
document.addEventListener("vviinnWidgetLoad", ({ detail }) => {
  console.log(detail);
});

// Output: Search Modal
{
  "campaignTypeId": "VPS",
  "campaignTypeName": "Visual Search",
  "widgetId": "",
  "widgetVersion": "2.85.0"
}
// Output: One-click Discovery
{
    "campaignTypeId": "VPR",
    "campaignTypeName": "Similar Products",
    "widgetId": "",
    "widgetVersion": "2.87.0"
}

```
