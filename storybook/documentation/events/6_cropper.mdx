# Cropper Events

Cropper events are used internally to connect the `vviinn-cropper` and `vviinn-results` components. They can also be used externally to handle crop operations manually (e.g., with `autoSearch={false}` for custom API integration).

<table width="100%" className="events-table">

    <tr><th>Name</th><th>Description</th><th>Props</th></tr>
  </thead>

  <tbody>

      <td>vviinnCropperLoadImage</td><td>Triggered when the image load in cropper.</td>

        <ul>
          <li>imageBounds - Image dimensions in pixels</li>
        </ul>
      </td>
    </tr>

    <tr>
      <td>vviinnCropperCropEnd</td><td>Triggered when crop ends with enriched data including normalized coordinates for visual-search API.</td>

      <td>
        <ul>
          <li>searchArea - Search area in absolute pixels</li>
          <li>normalizedSearchArea - Normalized search area (0-1 range) ready for visual-search API</li>
          <li>imageBounds - Image dimensions in pixels</li>
          <li>requestId - Optional search/request ID for API continuity</li>
        </ul>
      </td>
    </tr>

  </tbody>
</table>

## Listen to Events. Examples

By default, the cropper automatically triggers visual search after crop ends. Set `autoSearch={false}` on the `vviinn-cropper` component to disable automatic search and handle the API call manually. The `vviinnCropperCropEnd` event will still fire with normalized data ready for API use.

```javascript
document.addEventListener("vviinnCropperCropEnd", ({ detail }) => {
  console.log(detail);

  // Use normalizedSearchArea directly in visual-search API:
  // query: { searchArea: detail.normalizedSearchArea }
});

// Output:
{
  "searchArea": { "left": 100, "top": 50, "width": 200, "height": 150 },
  "normalizedSearchArea": { "left": 0.125, "top": 0.083, "width": 0.25, "height": 0.25 },
  "imageBounds": { "left": 0, "top": 0, "width": 800, "height": 600 },
  "requestId": "abc-123-def"
}
```
