# Text Search Events

Every Vviinn Widget has some events that users can work on and listen to these events with `document.addEventListener()`.

Text Search events are essential to connect `vviinn-text-search` and `vviinn-results` components.

All these events are available on Text Search.

<table width="100%" className="events-table">
  <thead>
    <tr><th>Name</th><th>Description</th><th>Props</th></tr>
  </thead>

  <tbody>
    <tr>
      <td>vviinnTextSearchStarted</td><td>Triggered when a text search was initiated.<br/><br/>Not emitted when:<br/>- <code>results-page-url</code> is set and the user is not on the results page<br/>- Query mapping returns an auto-suggest redirect<br/><br/>In both cases, <code>vviinnRedirect</code> is emitted instead.</td>

      <td>
        <ul>
          <li>query</li>
          <li>isTriggeredByVpsWidget</li>
        </ul>
      </td>
    </tr>

    <tr>
      <td>vviinnImageUploadFinished</td><td>Triggered when an image search ID was received.</td>

      <td>
        <ul>
          <li>searchId</li>
          <li>isTriggeredByVpsWidget</li>
        </ul>
      </td>
    </tr>

  </tbody>
</table>

## Listen to Events. Examples

```javascript
document.addEventListener("vviinnTextSearchStarted", ({ detail }) => {
  console.log(detail);
});

// Output:
{
  "query": "kitchen",
  "isTriggeredByVpsWidget": false
}
```
