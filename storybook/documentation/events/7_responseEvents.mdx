# Response Events

These events are triggered by backend responses and contain instructions or suggestions from the API server.

These props are available for each event:

- campaignTypeId
- campaignTypeName
- widgetId (if exists)
- widgetVersion

Some events have additional props, summarized in the table below.

<table width="100%" className="events-table">
  <thead>
    <tr><th>Name</th><th>Description</th><th>Available on</th><th>Props</th></tr>
  </thead>

          <li>vviinn-vps-button (Search Button)</li>
          <li>vviinn-vps-widget (Search Modal)</li>
          <li>vviinn-results (Product List)</li>
        </ul>
      </td>

        <ul>
          <li>url</li>
        </ul>
      </td>
    </tr>

    <tr>
      <td>vviinnNoResult</td>
      <td>Triggered when an error has occurred after:<br/>- Product AI recommendation request<br/>- Visual search request (image upload, crop, rotate, select object)<br/>- Text search request<br/>- Product listing page request<br/>- Image validation (wrong format)</td>
      <td>
        <ul>
          <li>vviinn-vpr-widget (Recommendation Widget)</li>
          <li>vviinn-vps-button (Search Button)</li>
          <li>vviinn-vps-widget (Search Modal)</li>

        </ul>
      </td>

  </tbody>

## Listen to Events. Examples

```javascript
document.addEventListener("vviinnRedirect", ({ detail }) => {
  console.log(detail);
  // Optionally redirect the user
  // window.location.href = detail.url;
});

// Output:
{
    "url": "https://www.my-site.de/sansibar",
    "campaignTypeId": "TPS",
    "campaignTypeName": "Text Product Search",
    "widgetId": "my-search-widget",
    "widgetVersion": "2.190.0"
}

document.addEventListener("vviinnNoResult", ({ detail }) => {
  console.log(detail);
  // Handle error - show notification, retry, etc.
});

// Output:
{
    "campaignTypeId": "TPS",
    "campaignTypeName": "Text Product Search",
    "widgetId": "my-search-widget",
    "widgetVersion": "2.202.0"
}
```
