# Response Events

These events are triggered by backend responses and contain instructions or suggestions from the API server.

These props are available for each event:

- campaignTypeId
- campaignTypeName
- widgetId (if exists)
- widgetVersion

Some events have additional props, summarized in the table below.

## Listen to Events. Examples

### Basic Usage of Redirect Event

```javascript
document.addEventListener("vviinnRedirect", ({ detail }) => {
  console.log(detail);
  // Widget will automatically redirect unless intercepted
});

// Output:
{
    "url": "https://www.my-site.de/sansibar",
    "query": "sansibar",
    "campaignTypeId": "TPS",
    "campaignTypeName": "Text Product Search",
    "widgetId": "my-search-widget",
    "widgetVersion": "2.205.0"
}
```

### Intercept Redirect

You can intercept the redirect by calling `event.preventDefault()` to handle navigation yourself.

```javascript
document.addEventListener("vviinnRedirect", (event) => {
  event.preventDefault();

  const { url, query } = event.detail;

  // Your custom logic: SPA routing, analytics, confirmation dialogs, etc.
  myRouter.push(url);
});
```

### Basic Usage of No Result Event

```javascript
document.addEventListener("vviinnNoResult", ({ detail }) => {
  console.log(detail);
  // Handle error - show notification, retry, etc.
});

// Output:
{
    "campaignTypeId": "TPS",
    "campaignTypeName": "Text Product Search",
    "widgetId": "my-search-widget",
    "widgetVersion": "2.202.0"
}
```
