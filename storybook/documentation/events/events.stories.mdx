# Listening events

Every `vviinn-product-card` generates 3 events:

- VviinnProductClick
- VviinnProductView
- VviinnProductLoad

Users can work and listen to these events with `document.addEventListener()`.

## Recommendation load and view

```javascript
document.addEventListener("VviinnProductLoad", ({ detail }) => {
  console.log(`Load product ${detail.title} with id ${detail.productId}`);
});

document.addEventListener("VviinnProductView", ({ detail }) => {
  console.log(
    `Product ${detail.title} with id ${detail.productId} is rendered on viewport`
  );
});
```

## Recommendation click

When a deeplink is clicked we dispatch `productClick()` and the user is redirected to the product. You can use [Beacon API](https://developer.mozilla.org/en-US/docs/Web/API/Beacon_API) to handle these events.

```javascript
document.addEventListener("VviinnProductClick", ({ detail }) => {
  navigator.sendBeacon(some_url, detail);
});
```
