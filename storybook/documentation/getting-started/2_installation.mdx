# JavaScript

## Install using CDN

Paste scripts to the `head` section of your page.<br />
Script with `nomodule` attribute is needed only for supporting browsers without JavaScript modules feature.

```html
<script
  type="module"
  src="STORYBOOK_CDN_PATH/STORYBOOK_NPM_PACKAGE_NAME.esm.js"
></script>
<script
  nomodule
  src="STORYBOOK_CDN_PATH/STORYBOOK_NPM_PACKAGE_NAME.js"
></script>
```

Then you will be able to use VPR or VPS widgets.

### Recommendation Widget

To use recommendation widget, insert a snippet below where you want to render the widget.<br />
`token` and `product-id` attributes are only necessary, but you can tweak the widget with other attributes.

```html
<STORYBOOK_VPR_WIDGET_TAG token="YOUR_TOKEN" product-id="YOUR_PRODUCT_ID">
</STORYBOOK_VPR_WIDGET_TAG>
```

[Check other attributes here ](?path=/story/playground-discovery--grid)

Also, it’s possible to create the component instance with DOM API:

```javascript
const component = document.createElement("STORYBOOK_VPR_WIDGET_TAG");
component.token = YOUR_TOKEN;
component.productId = YOUR_PRODUCT_ID;

document.append(component);
```

### Search Widget

To use the search widget, first, insert the snippet below anywhere on the page.
The widget is implemented as a modal window, so you need to trigger it.

```html
<STORYBOOK_VPS_WIDGET_TAG token="YOUR_TOKEN"></STORYBOOK_VPS_WIDGET_TAG>
```

[Check other attributes here ](?path=/story/playground-search-modal--default)

You can also create a component instance with DOM API:

```javascript
const component = document.createElement("STORYBOOK_VPS_WIDGET_TAG");
component.token = YOUR_TOKEN;

document.append(component);
```

## Install using NPM

To use widgets as ES6 modules you should install them from [NPM](https://www.npmjs.com/package/vviinn-widgets).

`npm i STORYBOOK_NPM_PACKAGE_NAME`

And then add it to your JavaScript code:

```javascript
import { defineCustomElements } from "STORYBOOK_NPM_PACKAGE_NAME";
defineCustomElements();
```

After that, you can use both Recommendation or Search Widgets in an HTML template or with Javascript.

# React

With an application built using the `create-react-app` script, the easiest way to include the component library is to call `defineCustomElements()` from the `index.js` file. If you are targeting Edge or IE11 in this scenario applyPolyfills is needed.

## JavaScript Example

In this example, we create an `importVviinn.js` file and import it in `App.js` and then, we can use Vviinn Widgets as shown below:

`importVviinn.js`

```javascript
import { applyPolyfills, defineCustomElements  } from 'vviinn-widgets/dist/loader';

applyPolyfills().then(() => {
  defineCustomElements();
});
```

`App.js`

```javascript
import "./importVviinn"

function App() {
  return (
    <div className="App">
      <vviinn-vps-button token="YOUR_TOKEN"></vviinn-vps-button>
    </div>
  );
}

export default App;
```

## TypeScript Example

In this example, we create an `importVviinn.ts` file and import it in `App.tsx` and then, we can use Vviinn Widgets as shown below:

`importVviinn.ts`

```typescript
import { applyPolyfills, defineCustomElements, JSX as LocalJSX  } from 'vviinn-widgets/dist/loader';
import { HTMLAttributes } from 'react';

type StencilToReact<T> = {
  [P in keyof T]?: T[P] & Omit<HTMLAttributes<Element>, 'className'> & {
    class?: string;
  };
} ;

declare global {
  export namespace JSX {
    interface IntrinsicElements extends StencilToReact<LocalJSX.IntrinsicElements> {
    }
  }
}

applyPolyfills().then(() => {
  defineCustomElements(window);
});
```

`App.tsx`

```typescript
import "./importVviinn"

function App() {
  return (
    <div className="App">
       <vviinn-vps-button token="YOUR_TOKEN"></vviinn-vps-button>
    </div>
  );
}

export default App;
```

## Troubleshooting

Sometimes other libraries define custom elements and there would be some conflict. In this case, you can integrate Vviinn Widgets as shown below:

### useScript.ts

With this `custom hook`, we will add related scripts to our page:

```typescript
import { useEffect } from "react";

export const useScript = (
  url: string,
  type: string = "",
  noModule: boolean = false
) => {
  useEffect(() => {
    const script = document.createElement("script");

    script.src = url;
    script.async = true;
    script.defer = true;
    script.type = type;
    script.noModule = noModule;

    document.body.appendChild(script);

    return () => {
      document.body.removeChild(script);
    };
  }, [url]);
};
```

### VviinnWidgets.ts

In this file, we define a wrapper for Vviinn Widgets and then render the widgets:

```typescript
import { FC } from "react";
import { useScript } from "./useScript";

type Tag = React.DetailedHTMLProps<
  React.HTMLAttributes<HTMLElement>,
  HTMLElement
>;

type ElementType = "vviinn-vps-button" | "vviinn-vpr-button";

declare global {
  namespace JSX {
    interface IntrinsicElements {
      "vviinn-vpr-button": VviinnTag & { "product-id": string };
      "vviinn-vps-button": VviinnTag;
    }
  }
}

type VviinnWidgetProps = {
  type: ElementType;
  token: string;
  productId?: string;
};

type ApiPath =
  | "https://api.vviinn.com"
  | "https://api.stage.vviinn.com/";

type VviinnTag = Tag & {
  token: string;
  "api-path": ApiPath;
};

export const VviinnWidget: FC<VviinnWidgetProps> = ({
  type,
  token,
  productId,
}) => {
  useScript(`${CDN_URL}vviinn-widgets.esm.js`, "module");
  useScript(`${CDN_URL}vviinn-widgets.js`, "", true);

  const apiPath: ApiPath = isProduction
    ? "https://api.vviinn.com"
    : "https://api.stage.vviinn.com/";

  const generalVviinnTagProps: VviinnTag = { token, "api-path": apiPath };

  return (
    <>
      {type === "vviinn-vpr-button" && productId && (
        <vviinn-vpr-button
          {...generalVviinnTagProps}
          product-id={productId}
          add-style="false"
        ></vviinn-vpr-button>
      )}

      {type === "vviinn-vps-button" && (
        <vviinn-vps-button {...generalVviinnTagProps}></vviinn-vps-button>
      )}
    </>
  );
};

```

Following the steps above will enable your web components to be used in React. However, there are some additional complexities that must also be considered. [Custom Elements Everywhere](https://custom-elements-everywhere.com) contains a synopsis of the current issues.

For more information, check [Stencil documentation](https://stenciljs.com/docs/react)

# Angular

Using a Stencil-built web component collection within an Angular CLI project is a two-step process. We need to:

* Include the `CUSTOM_ELEMENTS_SCHEMA` in the modules that use the components.
* Call `defineCustomElements()` from main.ts (or some other appropriate place).

## Including the Custom Elements Schema

Including the `CUSTOM_ELEMENTS_SCHEMA` in the module allows the use of the web components in the HTML markup without the compiler producing errors. This code should be added to the `AppModule` and every other module that uses your custom elements. Here is an example of adding it to `AppModule`:

```javascript
import { BrowserModule } from '@angular/platform-browser';
import { CUSTOM_ELEMENTS_SCHEMA, NgModule } from '@angular/core';
import { FormsModule } from '@angular/forms';

import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule, FormsModule],
  bootstrap: [AppComponent],
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
})
export class AppModule {}
```

The `CUSTOM_ELEMENTS_SCHEMA` needs to be included in any module that uses custom elements.

## Calling defineCustomElements

A component collection built with Stencil includes a main function that is used to load the components in the collection. That function is called `defineCustomElements()` and it needs to be called once during the bootstrapping of your application. One convenient place to do this is in `main.ts` as such:

```javascript
import { enableProdMode } from '@angular/core';
import { platformBrowserDynamic } from '@angular/platform-browser-dynamic';

import { AppModule } from './app/app.module';
import { environment } from './environments/environment';

// Note: loader import location set using "esmLoaderPath" within the output target config
import { defineCustomElements } from 'STORYBOOK_NPM_PACKAGE_NAME/loader';

if (environment.production) {
  enableProdMode();
}

platformBrowserDynamic().bootstrapModule(AppModule)
  .catch(err => console.log(err));
defineCustomElements();
```

For more information, check [Stencil documentation](https://stenciljs.com/docs/angular)

# Vue

To use the custom element library within the Vue app, the application must be modified to define the custom elements and to inform the Vue compiler which elements to ignore during compilation. This can all be done within the `main.js/ts` file.

As you see in the following example, we imported `applyPolyfills` and `defineCustomElements` from `vviinn-widgets/dist/loader` and then in the next line calling `applyPolyfills()` and `defineCustomElements()` to register the Vviinn Widgets. The rest is related to Vue itself.

`main.js/main.ts`

```javascript
import './assets/main.css'

import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

import { applyPolyfills, defineCustomElements } from 'vviinn-widgets/dist/loader'

applyPolyfills().then(() => {
  defineCustomElements()
})

const app = createApp(App)

app.use(router)

app.mount('#app')
```

`In a Vue component`

```javascript
<script setup lang="ts"></script>

<template>
  <vviinn-vps-button token="YOUR_TOKEN"></vviinn-vps-button>
</template>

<style scoped></style>
```

## \[Vue warn]: Failed to resolve component: ...

If you see the following Vue warning in the browser console:

`If this is a native custom element, make sure to exclude it from component resolution via compilerOptions.isCustomElement.`

You can fix it by adding the following code to the `vue.config.js/ts` file:

```javascript
export default defineConfig({
  plugins: [
    ...
    vue({
      template: {
        compilerOptions: {
          isCustomElement: (tag) => {
            return tag.startsWith('vviinn-')
          }
        }
      }
    }),
    ...
  ],
  ...
})
```

## Troubleshooting

Sometimes other libraries define custom elements and there would be some conflict. In this case, you can integrate Vviinn Widgets as explained in the [Frameworkless](?path=/docs/installation-frameworkless--docs) section.

For more information, check [Stencil documentation](https://stenciljs.com/docs/vue)

# Mobile App (WebView)

In mobile app development, a `WebView` is an essential component that allows you to display web content within your native `Android` or `iOS` app. Therefore, in this section we want to show you how to integrate `Vviinn Widgets` as a web component in a mobile app.

If you are interested to learn more about the `WebView` component, you can check the official documentation for [Android](https://developer.android.com/reference/android/webkit/WebView) and [iOS](https://developer.apple.com/documentation/webkit/wkwebview). If you are also developing mobile apps with Cross-Platform development technologies, there are some popular libraries like [React Native WebView](https://www.npmjs.com/package/react-native-webview), [Flutter WebView](https://pub.dev/packages/webview_flutter), [Ionic WebView](https://ionicframework.com/docs/core-concepts/webview) and others that you can use based on your technology stack.

## Integration

The first step of integrating `Vviinn Widgets` is to create some HTML files and locate them in an HTTPS server. If you want to know how to integrate `Vviinn Widgets` as a web component in a web page, you can check the [Frameworkless integration](?path=/docs/installation-frameworkless--docs) page.

Now you have a URL which when opened in a browser shows `Vviinn Widgets`. Recommendation widgets can be passed (as HTML) to `WebViews` on fly. Search widget requires HTTPS to be able to show the camera, so in this case we highly recommend hosting the HTML file on a server.

After that, you need to integrate the `WebView` component into your mobile app. Here are some requirements that you need to consider:

- Enable Javascript in the `WebView` component.
- Set JavaScript mode to unrestricted.
- Add listeners for the `Vviinn Widgets` events in the `WebView` component. You can see the list of events on the [Events](?path=/docs/getting-started-events--docs) page.
- Load the `WebView` with the URL or pass the HTML to it.
- Give Camera permission to the app.

### Permissions

#### Android
On Android, you need to add these permissions in your `AndroidManifest.xml` file to be able to use a camera for taking images and videos:
```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
<uses-permission android:name="android.permission.VIDEO_CAPTURE" />
<uses-permission android:name="android.permission.AUDIO_CAPTURE" />
```

#### iOS
On iOS, you need to add the following properties in your `Info.plist` file to be able to use a camera for taking images and videos:
```xml
<key>NSMicrophoneUsageDescription</key>
<string>Flutter requires acess to microphone.</string>
<key>NSCameraUsageDescription</key>
<string>Flutter requires acess to camera.</string>
```

### Flutter Integration Example
Here is an example of how you can do this in `Flutter`:

```js 
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';
import 'package:permission_handler/permission_handler.dart';

Future main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Permission.camera.request();
  await Permission.microphone.request();

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
        useMaterial3: true,
      ),
      home: const MyHomePage(title: 'Flutter Demo Home Page'),
    );
  }
}

class MyHomePage extends StatefulWidget {
  const MyHomePage({super.key, required this.title});

  final String title;

  @override
  State<MyHomePage> createState() => _MyHomePageState();
}

class _MyHomePageState extends State<MyHomePage> {
  late WebViewController controller;

  @override
  void initState() {
    super.initState();
    controller =
        WebViewController(onPermissionRequest: (request) => request.grant())
          ..enableZoom(true)
          ..setJavaScriptMode(JavaScriptMode.unrestricted)
          ..addJavaScriptChannel(
            'vviinnProductClick',
            onMessageReceived: (JavaScriptMessage message) {
              debugPrint("vviinnProductClick \"${message.message}\"");
            },
          )
          ..setNavigationDelegate(NavigationDelegate(
            onPageFinished: (String url) {
              controller.runJavaScript('document.addEventListener("vviinnProductClick", ({ detail }) => {vviinnProductClick.postMessage(detail.productId);});');
            },
          ))
          ..loadRequest(
            Uri.parse('URL_TO_YOUR_HTML_FILE'),
          );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        centerTitle: true,
        title: const Text("test"),
      ),
      body: WebViewWidget(
        controller: controller,
      ),
    );
  }
}

```

In this example, we also asked for microphone permission, but only the camera permission is required.

We also used 2 packages, `webview_flutter` and `permission_handler` to be able to use WebView and ask for camera permission. However, you can use any package which suits your needs.

To redirect to the product details page that you have in your mobile app you need to listen to the `vviinnProductClick` event and based on the `product ID` redirect to the product details page. To prevent the default redirection, you should set the `product-details-redirect` property to `false` in your widget component.

# Nuxt

In this section, you can learn how to use the Vviinn Widgets in your Nuxt app.

## Install using CDN

Using this way, you need to add Vviinn scripts to the `head` section to be able to use Vviinn Widgets as shown below:

```javascript
<template>
  <div>
    <vviinn-vps-widget
      token="YOUR_TOKEN"
    ></vviinn-vps-widget>

    <Script src="https://cdn.jsdelivr.net/npm/vviinn-widgets/www/build/vviinn-widgets.esm.j" type="module"></Script>
  </div>
</template>
```

## Install using NPM

To use widgets as a module you should install Vviinn Widgets from [NPM](https://www.npmjs.com/package/vviinn-widgets).

Then create a `client component` in Nuxt and import the Vviinn Widgets as shown below:

```javascript
<script>
import {applyPolyfills, defineCustomElements } from 'vviinn-widgets/dist/loader';

applyPolyfills().then(() => {
  defineCustomElements()
})
</script>

<template>
  <div>
    <vviinn-vps-button 
      token="YOUR_TOKEN"
    ></vviinn-vps-button> 
  </div>
</template>
```

The final step will be to use this client component.

## Fix [Vue warn]: Failed to resolve component: vviinn-...

To fix the "Failed to resolve component" warning, you need to add the following code to the `nuxt.config.js` file:

```javascript
export default defineNuxtConfig({
  ...,
  vue: {  
    compilerOptions: {
      isCustomElement:  (tag) => {
        return tag.startsWith('vviinn-')
      },
    },
  },
  ...
})
```

Note: This document has been prepared based on Nuxt v3.13.
