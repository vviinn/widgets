# Register

In order to use `Vviinn Widgets` you need to have a product feed in `Vviinn Panel`. In the following section we will introduce the steps:

- [Register](https://panel.vviinn.com/auth/register) / [Login](https://panel.vviinn.com/auth/signin) on [Vviinn Panel](https://panel.vviinn.com).
- If you are a new user, you will be redirected to `self onboarding` process to set up `Vviinn visual relevance machine` in the simplest way for you.
    - Please verify your email, than you can choose "Start Free Trial".
    - As soon as you enter the company and personal information, you will get redirected to the panel. There a 10 steps tour guide will start.
    - After finishing the self onboarding, you will have all necessary panel configuration, including company, site, campaigns and an imported product feed.
- Go to [Sites](https://panel.vviinn.com/company/J/sites) menu, select the active site and copy the `Read Only` token.

Read only token allows you to use Vviinn Widgets on your site and show the result. Also, you can use the token in the Playground section of this storybook to test the functionality.
