# Register

To use `Vviinn Widgets` you need to have an imported product feed in `Vviinn Panel`. Here are the steps to achieve this:

- [Register](https://panel.vviinn.com/auth/register) / [Login](https://panel.vviinn.com/auth/signin) via [Vviinn Panel](https://panel.vviinn.com).
- If you are a new user, you will be redirected to the `self-onboarding` process to set up `Vviinn Visual Relevance Machine` in the simplest way for you.
    - Please verify your email, then you can choose "Start Free Trial".
    - As soon as you enter the company and personal information, you will be redirected to the Panel. Then a 10-step tour guide will start.
    - After finishing the self-onboarding, you will have all necessary panel configurations, including company, site, campaigns, and an imported product feed.
- Go to the [Sites](https://panel.vviinn.com/company/J/sites) menu, select the active site, and copy the `Read Only` token.

Read Only token allows you to use Vviinn Widgets on your site and show the result. Also, you can use the token in the Playground section of this storybook to test the functionality.
