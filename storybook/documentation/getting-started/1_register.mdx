# Register

In order to use `Vviinn Widgets` you need to have a product feed in `Vviinn Panel`. In the following section we will introduce the steps:

- [Register](https://panel.vviinn.com/auth/register) / [Login](https://panel.vviinn.com/auth/signin) on [Vviinn Panel](https://panel.vviinn.com).
- If you are a new user, you will automatically redirected to `self onboarding` process. In this step our goal is to set up `Vviinn visual relevance machine` in the most simplest way for you.
After verifying the email, you can choose "Start Free Trial" in order to start the self onboarding process.
- As soon as you enter the company and personal information, you will redirect to the panel. There, a tour guide will start which in 10 steps help you set up everything.
- After finishing the self onboarding, you will have a company, site, campaigns and an imported product feed,.
- Now it is the time to go to [Sites](https://panel.vviinn.com/company/J/sites) menu, select the active site and copy the `Read Only` token.

Having the Read only token allows you to use Vviinn Widgets on your site and show the result. Also, you can use the token in the Playground section and test the functionality there.
