# Vviinn Widgets

By using Vviinn widgets you can easily integrate your website with Vviinn's visual relevance machine that uses machine learning to analyze product images in a split second and use this data to create the most relevant digital shopping experience for users.

## Widget Types

We have `VPR` (Recommendation) and `VPS` (Search) widget types. Each one provides you with `button` and `widget` components. Recommendation Widget supports 2 campaign types: `VPR` and `VCS`. You can see the campaign types in the table below:

  <thead>
    <tr><th>Campaign Type ID</th><th>Campaign Type Name</th></tr>
  </thead>
