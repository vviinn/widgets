# Vviinn Widgets
## v. {dependencies['vviinn-widgets'].replace('^', '')}

By using Vviinn widgets you can easily integrate your website with Vviinn's visual relevance machine that uses machine learning to analyze product images in a split second and use this data to create the most relevant digital shopping experience for users.

## Widgets Types

We have `Visual Recommendation` and `Visual Search` widget types. Each one provides you with `button` and `widget` components.

## Widgets

You can see the widgets in action in the `Widgets` menu as listed below:

- Visual Recommendations
  - [Button](?path=/story/widgets-visual-recommendations-button--default)
  - [Widget](?path=/story/widgets-visual-recommendations-widget--grid)
- Visual Search
  - [Button](?path=/story/widgets-visual-search-button--default)
  - [Widget](?path=/story/widgets-visual-search-widget--default)
