# Releases

For releases we are using [semantic versioning](https://docs.npmjs.com/about-semantic-versioning) and tags.

To change version you should add it after *@* symbol. *latest* is used by default.

*latest* tag always contains the latest stable version.
*beta* tag can contain pre-released features.

```
<script type="module" src="https://cdn.jsdelivr.net/npm/vviinn-widgets@VERSION/www/build/vviinn-widgets.esm.js"></script>
<script nomodule src="https://cdn.jsdelivr.net/npm/vviinn-widgets@VERSION/www/build/vviinn-widgets.js"></script>
```
or

```
npm install vviinn-widgets@VERSION
```

You can find all available versions and tags on [npm page](https://www.npmjs.com/package/vviinn-widgets)
